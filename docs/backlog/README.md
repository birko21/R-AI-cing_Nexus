# Racing Intelligence Lab backlog

This backlog decomposes the V1.1 execution prompt and the long-term master specification into dependency-ordered epics and implementation tickets.

## Delivery rules

- Work through G0–G3 first using synthetic data only.
- Keep provider rights, public-web scraping, and production deployment behind explicit capability and entitlement gates.
- A ticket is complete only when its acceptance criteria, tests, documentation, and evidence are present.
- Synthetic and `SCRAPED_PUBLIC` data must never be presented as licensed or as proof of predictive skill.
- No ticket may add wagering, order placement, bookmaker credentials, or an undisclosed external data path.
