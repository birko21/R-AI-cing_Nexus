# Harness specialist features and position scenarios

RIL-052 defines an experimental harness scenario contract for start type, row/barrier, pacing, sectional time and running-line hypotheses. Every input carries missingness and source receipt IDs. Only pre-cutoff facts are used; future receipts are retained as excluded provenance.

Scenario outputs are labelled `EXPERIMENTAL_UNCALIBRATED`. Running-line and position statements are hypotheses for scenario exploration, not causal explanations, validated predictions, current official facts or wagering advice. Missing history returns `NOT_AVAILABLE` and does not invent a scenario.
