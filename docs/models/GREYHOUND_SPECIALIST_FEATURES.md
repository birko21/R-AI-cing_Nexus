# Greyhound specialist features and interference

RIL-053 defines descriptive greyhound inputs for box, first split, early acceleration, bend/run line, grade, trouble and interference. Each value carries source receipt IDs and explicit missingness. A reserve activation is allowed to recompute only a caller-supplied authorised feature set; all other values and provenance remain unchanged.

The synthetic fixture demonstrates the authorised recomputation boundary. It does not establish causal interference effects, a validated model, an official current fact or wagering advice. Missing history remains unavailable rather than being inferred.
