# Four-provider capability matrix

## Evidence boundary

This matrix is an audit of the existing `KirkMathie/The-long-straight` implementation, tests and validation reports. The audit snapshot is the public `main` commit `3ce0da06605e01d93d48398dc8ed471aa5c294f3`, inspected on 10 October 2026. The sibling repository was cloned read-only; no source, credential, deployment or production data was changed.

Code evidence is not entitlement evidence. “Available” means that the sibling code contains a parser, adapter or validator for the capability. “Not evidenced” is intentionally not treated as “not available”. Every provider remains disabled in Racing Intelligence Lab until its own access, licence, retention, display and model-use gates pass.

## Interpretation

The matrix separates four questions that must not be collapsed:

1. Can an adapter parse a field?
2. Can the provider supply it for the required racing code and time window?
3. May this application retain, display or use it in a model?
4. Is the evidence strong enough for an out-of-sample claim?

Only the first question is answered by code alone. A provider can be technically useful and still remain blocked. Betfair is therefore a first-class market-intelligence design input, but not a live source: catalogue identity, read-only price snapshots, liquidity, price history and starting-price evidence each receive separate provenance and entitlement checks.
